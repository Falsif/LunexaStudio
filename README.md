# LUNEXA Studio — YouTube Creator Manager

Android-приложение (Kotlin + Jetpack Compose) — личный центр управления игровым YouTube-каналом.
Не видеоредактор: никаких инструментов монтажа, обложек и записи.

## Статус: этап 1 (рабочая основа)

| Раздел | Что работает |
|---|---|
| **Главная** | Название/аватар канала, подписчики, просмотры, видео, просмотры за 7/28 дней, изменение подписчиков, цель, следующая и последняя публикация, «Важное» (просрочки, задачи на сегодня), график роста, быстрые кнопки |
| **Аналитика** | Ручные записи показателей из YouTube Studio, фильтр периода (7/28/90 дней, год, всё время), графики подписчиков и просмотров, сравнение Shorts / длинных / TikTok, игры по просмотрам, лучшие ролики |
| **Календарь** | Месяц / неделя / день / список, фильтр по типу, цвет по типу, статусы (Идея → Отменено), просроченные, повторы (серии), напоминания, перенос (+1 день / +1 неделя / любая дата), шаблоны: Shorts ежедневно в 13:25, длинные еженедельно, TikTok |
| **Идеи** | Все поля из ТЗ, поиск, фильтры (тип, статус, избранное), сортировка, превращение идеи в публикацию |
| **Библиотека игр** | Обложка из галереи, платформа, жанр, часы, статус, заметки; счётчики опубликованных/запланированных и сумма просмотров; связанные идеи и публикации |
| **Задачи** | Приоритеты, сроки, повторы (следующая создаётся при выполнении), напоминания, история, быстрые шаблоны |
| **Настройки** | Название пространства, канал, аватар, цель, язык RU/EN, часовой пояс (по умолчанию Asia/Novosibirsk), время по умолчанию, уведомления (все отключаемы), акцентный цвет, экспорт/импорт JSON, сведения о приложении |

Данные хранятся локально (Room/SQLite + DataStore), приложение полностью работает офлайн.
Уведомления переживают перезагрузку телефона.

Пока YouTube API не подключён, показатели канала вводятся вручную — это явно подписано в интерфейсе.
Разделы этапов 2–3 (ИИ, цели, монетизация, SEO) видны в «Ещё» с пометкой «Этап N» и не притворяются рабочими.

## Сборка APK

### Через GitHub Actions (без Android Studio)
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Сборка запустится сама (или: вкладка **Actions → Build APK → Run workflow**).
3. Через ~5–8 минут скачайте артефакт **LUNEXA-Studio-APK** → внутри `app-debug.apk` и `app-release.apk`.

`app-release.apk` подписан debug-ключом, чтобы его можно было сразу установить.
Для Google Play нужен собственный keystore.

### Через Android Studio
Откройте папку проекта (Android Studio Ladybug или новее, JDK 17).
Студия сама скачает Gradle 8.10.2 (указан в `gradle/wrapper/gradle-wrapper.properties`).
Чтобы собирать из терминала, один раз выполните `gradle wrapper` — появятся `gradlew` и `gradlew.bat`.
Затем **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.

## Технологии
Kotlin 2.0.21 · Compose BOM 2024.12 · Material 3 · Navigation Compose · Room 2.6.1 (KSP) · DataStore ·
kotlinx.serialization · Coil · AlarmManager. minSdk 26 (Android 8.0), targetSdk 35.

## Структура
```
app/src/main/java/com/lunexa/studio/
  data/      модели, Room, настройки, репозиторий, бэкап, статистика
  notify/    напоминания, уведомления, восстановление после перезагрузки
  ui/        тема, общие компоненты, навигация
  ui/screens/ экраны
```

## Следующие этапы

**Этап 2 — аналитика YouTube.** Google OAuth 2.0 (только scope
`youtube.readonly` и `yt-analytics.readonly`), YouTube Data API + YouTube Analytics API, синхронизация
по запросу с датой последней синхронизации, токены — в EncryptedSharedPreferences / Android Keystore.
Понадобится проект в Google Cloud Console и OAuth-клиент типа Android (package `com.lunexa.studio` + SHA-1 ключа подписи).

**Этап 3.** ИИ-помощник через настраиваемый API (ключ вводит пользователь или используется ваш сервер-прокси;
ничего не вшивается в APK), анализ «что работает лучше», цели и достижения, трекер монетизации
(с учётом региональных ограничений и разницы между оценочным и подтверждённым доходом), SEO-инструменты.
